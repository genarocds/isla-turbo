# Isla Turbo

An original arcade street racer set at night on a San Juan, Puerto Rico seafront, with a built-in reggaeton radio.

Open `index.html` in a browser (it loads three.js from cdnjs). Click **¡DALE!** to start; audio starts on that click.

- 3 laps against 3 AI rivals, with drifting, nitro, near-miss bonuses, a minimap and a speedometer
- 3 cars to choose from: Coquí GT, Flamboyán R, Mofongo V8
- **Radio Coquí 103.5**: 4 original tracks generated live with Web Audio (dembow kick and snare, sliding 808 bass, pads, timbal fills, synth hooks). No samples or copyrighted music.

| Key | Action |
| --- | --- |
| W / ↑ | Accelerate |
| S / ↓ | Brake / reverse |
| A D / ← → | Steer |
| Space | Handbrake / drift (charges nitro) |
| Shift | Nitro |
| C | Camera |
| R | Reset to track |
| N / M | Next song / mute music |

On touch devices, on-screen buttons appear.
